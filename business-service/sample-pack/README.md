# Fictional Dhaka Cafe — Sample Pack

This folder contains a demonstration pack for **Sample Local Cafe**, a fictional business in Dhaka. It is portfolio practice only, not a real client, testimonial, or performance case study.

- Audience: local residents and students
- Offer: coffee, tea, and light snacks
- Channel: Facebook
- Goal: start useful conversations and explain how to ask for current details
- Safety: no prices, opening hours, customer reviews, or performance claims are invented
- Approval: every caption is a draft; nothing is published

Use this as a layout example. For a real business, confirm details with the owner and replace all fictional information before delivery.
