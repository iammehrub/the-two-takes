# Two Takes Podcast studio artwork

Place the generated 16:9 channel image at this exact path:

`assets/two_takes_podcast_studio.jpg`

The production script will use it as the YouTube thumbnail (converted to 1280 × 720 JPEG) and show the same picture full-screen during the first four seconds of the video while narration continues. Subtitle timing is preserved.

If the image is not present, the pipeline safely falls back to its existing thumbnail and video visuals. Upload the image from the ChatGPT download link to this folder using the exact filename above to activate the branding.
